Das Datenmodell

Fünfzehn Tabellen, in denen ein Leihradsystem sich merkt, welches Rad wo steht, wer damit gefahren ist und was dabei kaputtging. Links der Einstieg für alle, die zum ersten Mal auf ein Datenmodell schauen — rechts dieselbe Sache technisch.

Vier Begriffe, dann können Sie das Bild lesen

Tabelle Eine Schublade für eine Sorte Ding. Alle Räder in die eine, alle Kunden in die andere. Nie beides gemischt.
Zeile und Spalte Jede Zeile ist ein einzelnes Ding — ein bestimmtes Rad. Jede Spalte eine Eigenschaft, die jedes Ding dieser Sorte hat.
Primärschlüssel Die Nummer, an der genau eine Zeile hängt. Wie eine Matrikelnummer: Namen doppeln sich, die Nummer nicht.
Fremdschlüssel Eine Spalte, die auf die Nummer in einer anderen Tabelle zeigt. So wird aus vielen Schubladen ein System.
Bereich

Linien sind Beziehungen. 1 und n sagen, wie viele zusammengehören: An einem Rad hängen n Fahrten — an einer Fahrt aber immer nur genau ein Rad.
